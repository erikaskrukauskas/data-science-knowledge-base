# Let the data challenge the function

Subject knowledge proposes the function. The measurements can reject it.

The NIST/SEMATECH e-Handbook states: "Fortunately, many physical systems can be modeled well with straight-line, polynomial, or simple nonlinear functions." ([Using the Data to Select an Appropriate Function](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd422.htm), checked 2026-10-17.)

## What to do

- If residuals show a systematic gap, the function is incomplete.
- Do not keep a preferred form by explaining away a clear pattern.
- A revised function needs its own check.
