# Select the function deliberately

The function is the claim about how the response moves. Select it on purpose.

The NIST/SEMATECH e-Handbook states: "(links provided below), provides one way to learn about the function shapes and flexibility." ([How do I select a function to describe my process?](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd42.htm), checked 2026-10-17.)

## What to do

- Compare a small set of functions the measurements could actually support.
- A function chosen because it fits best among dozens is an exploratory result.
- Say what the function cannot represent.
