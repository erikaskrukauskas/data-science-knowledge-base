# Project reliability to the use condition you named

A reliability projection at use conditions is the accelerated result carried through the acceleration model, and the use condition has to be stated.

The NIST/SEMATECH e-Handbook states: "However, it is frequently necessary to test at high stress (to obtain any failures at all!) and project backwards to use." ([How do you project reliability at use conditions?](https://www.itl.nist.gov/div898/handbook/apr/section4/apr43.htm), checked 2026-10-19.)

## What to do

- Name the use stress and the acceleration model.
- Report the projected reliability with the uncertainty of that extrapolation.
- Do not present the high-stress reliability as the use reliability.
