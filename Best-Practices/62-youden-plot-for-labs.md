# Compare methods with a Youden plot

A Youden plot compares two measurements of the same items.

The NIST/SEMATECH e-Handbook states: "Youden plots should be a routine plot for analyzing this type of data." ([Youden Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3331.htm), checked 2026-10-17.)

## What to do

- Points off the diagonal disagree. A cloud shifted off the diagonal is a bias between the methods.
- Use it before you treat two labs or two instruments as interchangeable.
- A high correlation can still hide a systematic shift.
