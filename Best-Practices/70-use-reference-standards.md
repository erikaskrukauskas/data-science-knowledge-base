# Use reference standards in calibration

Reference standards are the known points a calibration is built from.

The NIST/SEMATECH e-Handbook states: "At the highest level, a primary reference standard is assigned a value by direct comparison with the reference base." ([Reference standards](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc312.htm), checked 2026-10-17.)

## What to do

- Their uncertainty enters the uncertainty of every calibrated value.
- Do not treat a standard as exact when its own certificate has a range.
- A calibration with too few standards cannot show curvature.
