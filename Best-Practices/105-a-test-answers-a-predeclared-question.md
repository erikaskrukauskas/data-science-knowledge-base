# A test answers a pre-declared question

A statistical test compares the measurements with a stated claim, such as 'these means are equal.'

The NIST/SEMATECH e-Handbook states: "It also provides guidance on the sample sizes required for these tests." ([What are statistical tests?](https://www.itl.nist.gov/div898/handbook/prc/section1/prc13.htm), checked 2026-10-17.)

## What to do

- The claim, the groups, and the error rule have to be declared before the test is read.
- A test chosen after seeing which one is significant answers a different, wider question.
- Report the comparison, not only the significance label.
