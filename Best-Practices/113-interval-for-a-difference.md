# Put an interval on a difference of means

The decision usually needs the size of a difference, not only a label that the groups differ.

The NIST/SEMATECH e-Handbook states: "Given two random samples from two populations, two-sided confidence intervals for the difference between the unknown population means are shown in the table below." ([Confidence intervals for differences between means](https://www.itl.nist.gov/div898/handbook/prc/section3/prc312.htm), checked 2026-10-17.)

## What to do

- Report an interval for the difference.
- An interval that excludes zero can still be too small to matter. Say the size that would change the decision.
- Check the assumptions the interval uses, including spread and independence.
