# Read a scatter plot

A scatter plot is the check on whether a relationship is linear, curved, absent, or dominated by a few points.

The NIST/SEMATECH e-Handbook states: "There is no statistical procedure, the scatter plot included, that proves cause-and-effect." ([Scatter Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/eda33q.htm), checked 2026-10-17.)

## What to do

- Fit a line only after the plot shows a form the line can represent.
- A single correlation hides a curve and a point that sits apart.
- Say what the plot showed, not only the fitted slope.
