# Use multiple sampling only with the full plan in view

Multiple sampling stages the inspection into several possible samples, and the protection is a property of the whole scheme.

The NIST/SEMATECH e-Handbook states: "Sometimes acceptance is not allowed at the early stages of multiple sampling; however, rejection can occur at any stage." ([What is Multiple Sampling?](https://www.itl.nist.gov/div898/handbook/pmc/section2/pmc25.htm), checked 2026-10-19.)

## What to do

- Write every accept, reject, and continue boundary before you start.
- Stop when the plan says stop. Another stage is not an option you add because the lot is close.
- Compare the scheme's curve with a single sample that spends the same worst-case inspections.
