# Treat reliability growth as a changing rate

Reliability growth means the failure rate is changing because the system is being improved.

The NIST/SEMATECH e-Handbook states: "A formal test procedure aimed at discovering and fixing causes of unreliability is known as a Reliability Improvement Test." ([How can you model reliability growth?](https://www.itl.nist.gov/div898/handbook/apr/section1/apr19.htm), checked 2026-10-17.)

## What to do

- A constant-rate model will misstate both the current rate and the projected one.
- Show the rate over time.
- A projection that improvements continue is an assumption. Name it.
