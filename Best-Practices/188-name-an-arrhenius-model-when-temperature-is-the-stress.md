# Name an Arrhenius model when temperature is the stress

An Arrhenius acceleration model is a specific claim about how a rate depends on temperature, and using it is an extrapolation choice.

The NIST/SEMATECH e-Handbook states: "The Arrhenius model predicts failure acceleration due to temperature increase." ([Arrhenius](https://www.itl.nist.gov/div898/handbook/apr/section1/apr151.htm), checked 2026-10-19.)

## What to do

- State the temperatures in the study and the use temperature.
- Say that the acceleration factor is the Arrhenius factor, not a generic multiplier.
- Do not apply an Arrhenius factor to a stress that is not temperature.
