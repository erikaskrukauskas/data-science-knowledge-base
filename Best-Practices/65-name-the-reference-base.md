# Name the reference base

A measurement is a comparison with a reference. Name that reference.

The NIST/SEMATECH e-Handbook states: "The reference base is the ultimate source of authority for the measurement unit." ([Reference base](https://www.itl.nist.gov/div898/handbook/mpc/section1/mpc112.htm), checked 2026-10-17.)

## What to do

- Without a reference base, two measurements are not known to be in the same units.
- A local instrument reading is not yet a result in the units the decision uses.
- Record the reference in the project notes, not the raw extracts.

## Where this stops

This page is the reusable rule. Dataset names, thresholds, and the numeric result stay in the project.
