# State a Type B uncertainty as a judgment, not as a repeat

A Type B uncertainty comes from a stated distribution for a source you did not observe as a repeat, and it is not a standard deviation computed from those repeats.

The NIST/SEMATECH e-Handbook states: "The distinguishing feature is that the calculation of the uncertainty component is not based on a statistical analysis of data." ([Type B evaluations](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc54.htm), checked 2026-10-19.)

## What to do

- Name the source: a calibration certificate, a resolution, a prior study, or an engineering bound.
- Write the distribution you assigned and why.
- Do not label a Type B component as if it were the standard deviation of repeated measurements.
