# State capability against named limits

Capability compares a stable process distribution with specified limits.

The NIST/SEMATECH e-Handbook states: "This is all covered in more detail in the process capability section of the process monitoring chapter." ([Assessing Process Capability](https://www.itl.nist.gov/div898/handbook/ppc/section4/ppc46.htm), checked 2026-10-17.)

## What to do

- Name the limits and the distribution you assumed.
- A capable process can still be the wrong process if the limits are not the decision's limits.
- Do not report a capability index without the plot of the measurements against those limits.
