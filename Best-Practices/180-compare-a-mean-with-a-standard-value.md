# Compare a mean with a standard value you did not estimate

A comparison with a standard value tests the data against a number that was stated, not against a second sample.

The NIST/SEMATECH e-Handbook states: "The purpose of the two-sided alternative is to rule out a possible process change in either direction." ([Are the data consistent with the assumed process mean?](https://www.itl.nist.gov/div898/handbook/prc/section2/prc22.htm), checked 2026-10-19.)

## What to do

- Write the standard and where it came from before you see the estimate.
- Report the estimate, the standard, and an interval.
- A standard you computed from the same data is not an external standard.
