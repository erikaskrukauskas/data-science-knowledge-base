# Choose the sample size for the comparison you will report

The sample size belongs to a stated comparison: the difference you want to detect, the uncertainty you can accept, and the variation you expect.

The NIST/SEMATECH e-Handbook states: "Lacking an exact value for the standard deviation requires some accommodation, perhaps the best estimate available from a previous experiment." ([Sample sizes required](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm), checked 2026-10-19.)

## What to do

- Write the difference that would change the decision.
- Use a planning value for the variation, and say where it came from.
- A sample that was sized for the mean does not automatically size a comparison of spreads or a proportion.
