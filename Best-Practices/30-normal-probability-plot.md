# Use a normal probability plot

A normal probability plot shows whether the measurements fall along the shape a normal model requires.

The NIST/SEMATECH e-Handbook states: "Questions The normal probability plot is used to answer the following questions." ([Normal Probability Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/eda33l.htm), checked 2026-10-17.)

## What to do

- Curvature, a tail, or a step is evidence against that shape.
- Use the plot before a test that assumes normality.
- If the plot bends, say so next to any normal-based interval.
